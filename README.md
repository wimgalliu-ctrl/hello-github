# hello-github 🚀

我的第一个 GitHub 仓库，旅程从这里开始。

## 这个仓库是做什么的？

它是我在 GitHub 上的第一个脚印——用来熟悉仓库、分支、提交（commit）这些基础概念。
以后的学习笔记、练手小项目，都会陆续搬进来。

## 目录规划

```
hello-github/
├── README.md      ← 你正在看的这个文件
├── hello.py       ← 传统的第一个程序
└── notes/         ← 学习笔记（持续更新）
```

## 快速开始

```bash
python hello.py
```

输出：

```
Hello, GitHub! 👋
```
